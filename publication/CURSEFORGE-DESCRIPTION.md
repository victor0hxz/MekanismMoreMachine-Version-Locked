# Mekanism MoreMachine: Version Locked

![Mekanism MoreMachine Version Locked](https://raw.githubusercontent.com/victor0hxz/MekanismMoreMachine-Version-Locked/main/publication/LOGO-VERSION-LOCKED.png)

An unofficial community-made port of **Mekanism MoreMachine** by **Lost Myself**, for **Minecraft 26.1.2** and **NeoForge**.

This project is **version locked to Minecraft 26.1.2**.

## More machines for your factory

Expand your Mekanism factory with additional machines, advanced processing and larger production lines.

- **Recycling and replication:** turn selected unwanted materials into scrap and use matter replication.
- **Planting and processing:** automate crops and add stamping, lathing and rolling machines.
- **Advanced factories:** process multiple operations with factory versions of additional machines.
- **Large machines and generators:** expand industrial production and power generation.

Some replicator and general-purpose recipes must be configured by the player, as in the original mod.

## Requirements and compatibility

Requires [**Mekanism: Version Locked 2.4 or newer**](https://www.curseforge.com/minecraft/mc-mods/mekanism-version-locked). Install matching versions on the server and clients.

Tested with **Mekanism Extras 1.4.2-fix5** and **Mekanism Additions, Generators and Tools 1.0**. This addon does not bundle Mekanism JARs.
