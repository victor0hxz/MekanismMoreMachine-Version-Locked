# Mekanism MoreMachine: Version Locked

![Mekanism MoreMachine](https://raw.githubusercontent.com/victor0hxz/MekanismMoreMachine-Version-Locked/main/publication/LOGO-VERSION-LOCKED.png)

A community-made compatibility port of Mekanism MoreMachine by Lost Myself for Minecraft 26.1.2 and NeoForge. This build is version locked to Minecraft 26.1.2.

## More machines for your factory

Adds recycling, planting, replicating and general-purpose machines, advanced factories, large machines and generators. Some replicator and general-purpose recipes must be configured by the player, as in the original mod.

## Compatibility

Use Mekanism Version Locked 2.4 or newer, with matching server and client versions. Tested with Mekanism Extras 1.4.2-fix5 and Mekanism Additions, Generators and Tools 1.0. No Mekanism JARs are embedded in this addon.

## Tested

Dedicated server and client startup; 200 machine/factory tiles, including 100 Extras factories; recycler and basic, ultimate and absolute recycling processing; GUI and JEI initialization. The Mekanism-side legacy compatibility fix was tested with the original Trash Cans 1.1.0.
