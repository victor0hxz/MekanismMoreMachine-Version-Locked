# Mekanism MoreMachine Version Locked — ATM11 0.9.0

Community compatibility build for Minecraft 26.1.2 / NeoForge 26.1.2.109.

Original mod by Lost Myself: https://github.com/lostmyself8/Mekanism-MoreMachine/tree/26.1
Original MIT license and features preserved.

Built against the installed Mekanism Version Locked 2.4, Additions/Generators/Tools 1.0 and Mekanism Extras 1.4.2-fix5. Mekanism is an external dependency; no Mekanism JAR is embedded in this addon.

Provides MoreMachine machines, advanced factories, large machines and generators. Some general-purpose machines and the replicator require user-defined recipes by upstream design. This port does not invent default replication recipes.

Local builds use the dependency JARs in libs. Run Gradle 9.2 with Java 25. All production machines and registries are included.
